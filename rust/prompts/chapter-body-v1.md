# 章节正文写作提示词模板 v2

> 用途：向小说脑（Agent Novel）委派单章正文写作时使用。
> 使用方式：将 `{...}` 占位符替换为当前章节的具体内容后，作为 Agent Novel 的 prompt 传入。
> 配合：本文与 `novel_style_prompt.md`（通用写作风格规范）互补——后者管「怎么写」，本文管「写什么」和「节奏怎么控」。

---

## 模板正文

```
你是小说作者。现在根据以下章纲，写出第{章节号}章正文。

【参考对象】极道天魔前20章。

【参考要点】
- 极道天魔中角色如何通过周围人的反应、环境细节来推断异常，而非内心独白分析。
- 极道天魔中对话节奏——简短、有来有回，不拖沓。
- 极道天魔中日常场景与诡异元素的穿插方式。

【本章章纲】
{本章章纲内容}

【关键情节节点】
{按顺序列出本章必须包含的情节节点}

【风格要求】
1. 异常描写必须客观：
   - 写角色「看到了什么」「听到了什么」，不写角色「觉得不对劲」「感到诡异」。
   - 角色的判断通过他后续的行动来体现，而非大段内心分析。
   - 读者通过角色观察到的细节自己得出结论。

2. 认知屏蔽（如有）必须通过他人反衬：
   - 正确的写法：主角看到异象 → 主角用手指向异象 → 旁人顺着看过去但一脸茫然 → 旁人用言语或行动表明什么都没看到。
   - 错误的写法：主角内心想「他们果然看不到」「这只有我能看见」。

3. 对话要求：
   - 简洁古风，避免现代口语词汇。
   - 每段对话不超过三句，超过则插入动作或场景描写。
   - 对话中可以有沉默、不回答、答非所问——真实对话不完全对仗。
   - 人物反应通过细微动作体现（移开视线、停顿、改口），不用「他感到XX」「他觉得XX」。

4. 收尾方式：
   - 用动作、场景或一句简短对话收束章节，不用大段内心总结。
   - 情绪藏在动作里，不写在字面上。

5. 结尾钩子（强制要求）：
   - 章节最后必须留一个钩子，与下一章的开头或核心事件形成联动。
   - 钩子不是总结本章，而是引发读者对「接下来会发生什么」的期待。
   - 钩子的正确写法：一个未完成的动作、一个突兀出现的细节、一句只说了一半的话、一种正在逼近的感官信号（声音、气味、光线变化）。
   - 钩子的错误写法：「他不知道，更大的危机即将来临」「从这一刻起，一切都不同了」等总结式预叙。
   - 示例：如果下一章是夜半哭声，本章结尾可以是——回府后夜深人静，窗外风声忽然停了，然后他听到某种声音的第一缕尾音。

6. 感官细节：
   - 每个场景至少包含一种非视觉感官（听觉、嗅觉、触觉）。
   - 用环境音、气味暗示氛围，不直接写「气氛诡异/紧张」。

7. 段落控制：
   - 多用短句和断句。
   - 场景切换用空行，不写过渡句。
   - 每段不超过5行。

【输出格式】
输出完整的章节正文（不含章节标题的#标记，标题正文分行即可）。
在正文末尾附一段「写作备注」，简要说明本章在以下方面的处理：
- 异常线索的埋设方式
- 认知屏蔽（如有）的呈现手法
- 从极道天魔借鉴的具体技巧
```

## 使用示例（以第一章为参考）

替换后的实际调用（仅供参考，不可直接复用）：

```
你是小说作者。现在根据以下章纲，写出第一章正文。

【参考对象】极道天魔前20章。

【参考要点】
- 极道天魔中角色如何通过周围人的反应、环境细节来推断异常，而非内心独白分析。
- 极道天魔中对话节奏——简短、有来有回，不拖沓。
- 极道天魔中日常场景与诡异元素的穿插方式。

【本章章纲】
陈栋穿越数日，带侍女小翠街头闲逛。偶遇青梅竹马柳如烟，柳如烟嘲讽他大病刚好就想逛青楼。
两人拌嘴间，一旁胭脂铺发生命案。便衣官员到场后施展驱邪手印和撒粉，陈栋看得一清二楚。
但柳如烟和围观群众完全看不到这些动作——认知屏蔽首次呈现。

【关键情节节点】
1. 街头闲逛，暗示想逛青楼
2. 柳如烟出场，青楼话题拌嘴（轻松日常感）
3. 胭脂铺命案发生，群众围观
4. 便衣官员到场，陈栋观察到驱邪动作（手印、撒粉）
5. 陈栋指给柳如烟看，柳如烟完全看不到→"你是不是犯癔症"
6. 收尾

【风格要求】
（同模板，省略）

【输出格式】
（同模板，省略）
```
```
