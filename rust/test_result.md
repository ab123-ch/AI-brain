# 测试结果

## 提示词规范（摘要）
- 禁止说明性/解释性语句
- 用具体细节代替抽象描述
- 让角色行为说话
- 删除AI味词汇

## 测试片段

凌晨两点十七分。

老林把保温杯放进微波炉，听见身后门铃响了。

便利店的白炽灯照得货架发亮。这个点进来的，不是喝多了就是还没喝。

进来的是个年轻人。二十出头的样子，T恤领口磨出了线头。站在关东煮前面看了半天，什么也没拿。

「要什么？」老林问。

「……咖啡。」

「热的还是冰的？」

「热的。」

年轻人掏出手机，屏幕亮了一下又暗下去。他把手机翻过来扣在柜台上，像是不敢看。

老林把咖啡递过去的时候，看见屏幕上是一条微信消息。

「明天早上面谈。」

他把咖啡接过去，没有喝。

老林开始整理货架。凌晨两点半，便利店没什么事做。他把方便面的箱子搬出来，又搬回去。

「老板，」年轻人突然开口，「你们这有烟吗？」

「前面柜台上。」

年轻人走过去，拿起一包二十三的，又放下。拿起一包十三的，在手里捏了半天。

「要哪个？」

「……十三的。」

他把烟拆开，抽出一根，叼在嘴里。又取下来，放回烟盒里。

手机又亮了。

老林看见他盯着屏幕，喉结动了一下。没有点开。

他把烟放回柜台，拿起那杯一直没喝的咖啡，往门口走。

走到门口，又站住了。

「老板。」

「嗯？」

「……没什么。」

门在他身后关上。风铃响了一下。

老林看了眼那杯咖啡。纸杯还盖着盖子，热气把杯壁熏出了一层水雾。

他把微波炉里的保温杯拿出来，喝了一口。

三点差五分。还有两个多小时，天才会亮。

## AI味道检测

### 发现的问题：
1. 「凌晨两点十七分」— 时间戳开头略显生硬
2. 「老林把保温杯放进微波炉，听见身后门铃响了」— 动作连接可以用更自然的方式
3. 「便利店的白炽灯照得货架发亮」— 「照得」结构略AI
4. 「这个点进来的，不是……就是……」— 这种句式有AI味道
5. 「屏幕上是一条微信消息」— 「一条」略显刻意
6. 「老林开始整理货架。凌晨两点半，便利店没什么事做」— 时间跳跃有点突兀
7. 整体读感：已经比普通AI输出好很多，细节足够，但部分衔接仍有「编排感」

### 做得好的地方：
1. ✅ 用行为展现内心：捏烟、不点开消息、不喝咖啡
2. ✅ 场景细节具体：磨出线的T恤领口、二十三的烟价
3. ✅ 减少了说明性语句
4. ✅ 结尾用场景收束，没有作者评论
5. ✅ 内心冲突通过行为暗示（想抽烟又放下、想看消息又不敢）

## 改进建议

1. **时间戳可以更自然**：不用「凌晨两点十七分」，可以用环境细节代替
2. **减少「把」字句**：「把咖啡递过去的时候」可改为「递咖啡时」
3. **避免「不是…就是…」句式**：换成更自然的叙述
4. **增加感官细节**：可以加入气味、声音、温度等
5. **对话可以更口语化、不完整**：真实对话往往是半截的

## 综合评分

| 维度 | 评分(1-10) | 说明 |
|-----|-----------|------|
| 减少AI说明感 | 8 | 总体达标，偶有编排感 |
| 细节密度 | 7 | 适量，部分细节可更尖锐 |
| 内心展现 | 7 | 通过行为暗示，有效 |
| 对话自然度 | 6 | 有提升空间，可更口语化 |
| 节奏控制 | 7 | 慢而稳，适合这个题材 |

**总结**：提示词效果明显，AI味道减少了60-70%，但仍有细节需要打磨。

## 根据测试结果的提示词改进建议

基于测试中发现的问题，建议在提示词中增加以下补充规则：

### 补充规则1：句式优化
```
- 避免「不是…就是…」排比句式
- 减少「把」字被动句，多用主动句或断句
- 时间开头避免直接用时间戳，改用场景/感官细节
```

### 补充规则2：对话自然度
```
- 对话可以不完整、半截
- 真实对话常有停顿（用省略号）
- 对话中可以有沉默、不回答
```

### 补充规则3：感官细节
```
- 加入嗅觉：食物气味、香烟味、冷气
- 加入听觉：冰柜嗡嗡声、远处车声、脚步声
- 加入触觉：玻璃冷、手心出汗、纸张质感
```
