# 世界观：随机副本与气血武道

## 1. 世界基础

这是一个仍在运转的现代社会：城市、法律、科技、政府、教育与日常生活都真实存在。副本是嵌入现实的异常征召机制，全球范围随机挑选人类，改变个人命运，却不抹去社会本身。

副本的规则来自其自身运行逻辑。参与者必须在限定环境中理解并遵守规则，规则杀可以直接夺走生命。副本不提供公平解释，也不保证人类能够提前获知全部条件。

## 2. 副本征召

### 2.1 进入

- 征召面向全球随机抽人，无预警、无固定对象、无规律可供普通人规避。
- 被抽中者无法拒绝，也不能通过躲藏、断网、离开城市或其他方式规避。
- 进入时，穿戴、手持、衣袋、随身背包中的物品一起进入；不在随身范围内的物品不会被带入。
- 进入副本后，现实中的时间与信息无法替代参与者对副本现场的观察和判断。

### 2.2 返回

- 通关者可以返回现实，并带回通关时实际仍由其携带的物品。
- 返回者的身体状态、在副本内获得的永久强化和可携带物品一并保留。
- 副本经历不会让现代社会、法律和政府失效；现实会以自身方式处理失踪、伤亡与异常记录。

### 2.3 死亡

- 副本内死亡者本人和尸体不会返回现实；死亡后遗落在副本且未被幸存者带走的物品也不会返回。幸存者可以回收并携带死者遗物返回。
- 现实中的身份档案、相关记录以及他人对死者的记忆保留；这些保留不等于本人归来。

## 3. 全民气血武道

### 3.1 社会基础

全民练武源自现实社会对副本的长期适应：更强的身体、更高的反应和更好的耐受能力，能显著提高副本存活率。武道因此逐步普及，但现代社会的法律、科技、政府机构和公共秩序仍在。

气血武道不是另一个脱离社会的文明体系。训练、医疗、教育、就业和治安仍受现实制度约束，个人力量不能自动获得超越法律的权力。

### 3.2 武道本质

气血武道是纯肉身道路，依靠饮食、训练、呼吸、恢复和意志锤炼身体，不依赖灵魂出窍、法术、血脉传承或外置规则能力。气血增长代表人体综合机能与生命强度提升，而不是掌握任意规则。

肉身强者仍须学习、观察并遵守副本规则。力量可以提高行动和承伤能力，不能把未知规则变成可硬扛的攻击。

### 3.3 气血如龙

顶尖气血武者的生命力和爆发力如龙，足以抗衡最低级副本中的低级鬼怪，争取生存与反击机会。但这不构成规则豁免：气血不能硬抗规则杀。

## 4. 副本物品

### 4.1 普通物品

普通物品只有现实中的常规功能，不具有规则能力；其进出副本遵循第2节的携带、返回与死亡规则。

### 4.2 永久强化物品

永久强化物品必须在副本内使用。使用产生的身体、能力或属性强化永久保留，并随通关者返回现实；离开副本后仍然有效。强化的具体范围以物品本身的效果为准，不能把一次性效果擅自扩大为万能能力。

### 4.3 规则法器

规则法器在现实中是普通物品，不能在现实直接发挥规则效果；在任意副本中生效并发挥规则效果。有效法器可以跨副本携带，具体使用条件、触发方式、限制和代价由该法器的规则决定。

具体法器的规则是否公开、如何获知，由后续法器或副本设计决定；其生效仍取决于具体条件。法器也不会因为被带回现实就永久失效或自行改变规则。

## 5. 主角的金手指

### 5.1 单一刻录槽

金手指的来源、名称和载体不作解释。它只有一个规则刻录槽，只能容纳一条被抽取并刻录的规则。

新规则刻录后会永久覆盖旧规则。旧规则不可找回、不可并存、不可切换；不存在仓库、备用槽或规则列表。

### 5.2 掠夺式抽取

- 金手指只能从仍然有效的规则法器中抽取规则。
- 抽取完成后，原规则法器被永久抽空，退化为普通物品。
- 不能从副本条文、鬼怪、环境、普通物品或其他非规则法器对象直接抽取规则。
- 抽取是对法器规则的掠夺，不是复制；每次选择都消耗唯一的有效法器并承担单槽覆盖后果。

### 5.3 环境豁免

刻录进唯一槽位的规则在现实与副本中都能使用，不受规则法器“现实为普通物品”的环境限制。该豁免只作用于主角已刻录的那一条规则，不延伸为对所有副本规则、规则杀或其他超常效果的免疫。

前中期，主角是绝对唯一能在现实使用规则力量的人。其他人即使接触过规则法器，也只能等进入副本后使用法器效果。

## 6. 世界阶段变化

### 6.1 前中期

副本与现实保持边界。规则法器在现实表现为普通物品，刻录规则在现实和副本均可使用，因此主角拥有绝对唯一的现实规则力量。全民气血武道持续发展，目标首先是提高副本存活率。

### 6.2 后期：副本降临现实

随着副本侵蚀现实并逐步降临，部分副本规则能够在现实生效，普通规则法器也不再受“现实无效”的限制。现实秩序因此承受持续改写，但现代社会、法律、科技和政府仍是必须面对的基础。

阶段变化不会抹平主角优势：主角仍可从有效规则法器中抽取规则、永久剥夺原法器效果，并用唯一刻录槽永久覆盖旧规则。优势是选择与代价管理，不是无限叠加或随意切换。

## 7. 核心限制速查

| 事项 | 唯一规则 |
|---|---|
| 征召 | 全球随机、无预警、不可拒绝规避 |
| 携带 | 穿戴、手持、衣袋、随身背包物品随人进入 |
| 返回 | 通关者带回通关时实际仍由其携带的物品；死者本人和尸体不返回；遗落且未被幸存者带走的物品不返回；身份档案、相关记录及他人记忆保留 |
| 武道 | 全民气血源于提高副本存活率；纯肉身；气血如龙不能硬抗规则杀 |
| 永久强化 | 必须在副本内使用，强化永久保留到现实 |
| 规则法器 | 现实普通、任意副本中生效并发挥规则效果，可跨副本携带；代价由具体规则决定 |
| 金手指 | 来源、名称、载体不解释；只有一个刻录槽 |
| 覆盖 | 新规则永久覆盖旧规则，无仓库、无切换、不可找回 |
| 抽取 | 仅能从有效规则法器抽取；原法器永久抽空；不能从条文、鬼怪、普通物品抽取 |
| 使用 | 刻录规则在现实与副本都能用 |
| 阶段 | 前中期主角绝对唯一现实规则力量；后期普通法器可在现实生效，但主角仍保留抽取、剥夺、单槽覆盖优势 |
