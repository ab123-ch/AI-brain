# 示例流转说明：用户查询节假日

> 本文档以一个具体的用户输入为例，完整展示 AI Brain Agent 系统各副脑之间的消息流转路径。
> 日期：2026-04-03

---

## 用户输入

```
"告诉我这个月有没有节假日？"
```

---

## Phase 1: 感知脑接收 + 解析 (~10ms)

感知脑是所有外部输入的唯⼀入口。

```
输入源: CLI / API
原始内容: "告诉我这个月有没有节假日？"

感知脑处理:
├── 解析格式: 文本输入, 中文, 疑问句
├── 提取意图: 查询日历/节假日信息
├── 分类打标:
│   ├── task_type: "知识查询"
│   ├── domain: "日历/时间"
│   ├── urgency: "低"
│   └── requires_action: false (只是查询，不需要修改文件)
└── 投递到消息总线

投递消息:
┌──────────────────────────────────────────────────┐
│ Message {                                        │
│   content: "告诉我这个月有没有节假日？",            │
│   tags: ["知识查询", "日历", "时间"],               │
│   intent: "日历节假日查询",                        │
│   context: { current_date: "2026-04-03" },       │
│   source: "cli"                                  │
│ }                                                │
└──────────────────────────────────────────────────┘
```

---

## Phase 2: 并行广播 (~5ms)

消息总线将消息广播给所有副脑和主脑，基于 tokio broadcast channel 实现零拷贝广播。

```
              消息总线 (tokio broadcast)
                    │
        ┌───────┬───┴───┬───────┬───────┐
        ▼       ▼       ▼       ▼       ▼
     推理脑   记忆脑   执行脑   校验脑   主脑
     (并行)   (并行)   (并行)   (并行)  (监听)
```

---

## Phase 3: 各副脑并行快思考 (~50ms)

所有副脑同时接收消息，各自独立进行快思考判断。

### 推理脑 (Prefrontal Cortex)

```
快思考: 经验库模式匹配

搜索经验库:
┌──────────────────────────────────────┐
│ experience_id: "exp_calendar_001"    │
│ trigger_pattern: "日历/时间查询"      │
│ reasoning_path:                     │
│   [识别日期 → 搜索 → 交叉验证 → 组装] │
│ tools_used: ["WebSearch"]           │
│ success_rate: 0.88                  │
│ use_count: 12                       │
└──────────────────────────────────────┘

匹配结果: 命中 "日历/时间查询" 模式
置信度: 0.88 > 阈值 0.7 → 命中!

输出:
├── 判定: ✓ 相关
├── 置信度: 0.88
├── 建议路径: 需要执行 WebSearch 搜索节假日信息
└── 建议工具: WebSearch
```

### 记忆脑 (Hippocampus)

```
快思考: 索引检索

搜索关键词: "节假日" + "4月" + "2026"

索引命中:
┌──────────────────────────────────────┐
│ 记忆片段: 用户上月问过清明节的安排     │
│ 相关度: 0.65                         │
│ 内容: "2026年清明节是4月4日"           │
│ 创建时间: 2026-03-15                  │
│ 来源: WebSearch + 用户确认            │
│ 可信度: 0.85 (上次已验证)              │
└──────────────────────────────────────┘

输出:
├── 判定: ✓ 相关
├── 置信度: 0.65 (有部分记忆可参考)
├── 记忆内容: 清明节 4月4日
└── 来源: 历史记忆 (上次 WebSearch + 用户确认)
```

### 执行脑 (Motor Cortex)

```
快思考: 工具注册表检查

工具可用性检查:
├── WebSearch: ✓ 可用
├── WebFetch: ✓ 可用
└── 其他工具: 就绪

当前阶段判断:
├── Phase 3 是判断阶段，尚不需要执行
└── 等待主脑调度指令

输出:
├── 判定: ✗ 暂不相关 (当前是判断阶段)
├── 备注: WebSearch 已就绪，等待指令
└── 可用工具: ["WebSearch", "WebFetch"]
```

### 校验脑 (ACC + Basal Ganglia)

```
快思考: 规则库快速扫描

安全性检查:
├── 任务类型: "知识查询" → 低风险
├── 是否涉及文件修改: 否
├── 是否涉及高危命令: 否
├── 是否涉及敏感数据: 否
└── 安全等级: ✓ 低风险，自动放行

输出:
├── 判定: ✓ 安全通过
├── 安全等级: 低风险
└── 需要用户授权: 否
```

## Phase 4: 主脑汇总 + 决策 (~20ms)

主脑收集所有副脑的快思考结果，进行权重排序和任务分配。

```
主脑收到的响应汇总:
┌────────────────────────────────────────────────────┐
│ 副脑     │ 判定       │ 置信度 │ 权重(历史) │ 建议  │
├──────────┼────────────┼────────┼───────────┼───────┤
│ 推理脑   │ ✓ 相关     │ 0.88   │ 0.70      │ WebSearch │
│ 记忆脑   │ ✓ 相关     │ 0.65   │ 0.50      │ 有历史记忆 │
│ 执行脑   │ ✗ 暂不需要 │ —      │ 0.60      │ 工具就绪  │
│ 校验脑   │ ✓ 安全通过 │ —      │ 0.80      │ 低风险   │
└────────────────────────────────────────────────────┘

主脑决策分析:
├── 任务类型: 知识查询 → 需要推理 + 可能需要搜索
├── 记忆脑有部分答案(清明节), 但不完整
├── 推理脑建议使用 WebSearch 获取完整信息
├── 校验脑确认安全
│
└── 最终决策:
    ├── 1. 调度执行脑执行 WebSearch: "2026年4月中国法定节假日"
    ├── 2. 推理脑做慢思考，结合搜索结果 + 记忆组装回答
    ├── 3. 校验脑做最终真实性校验
    └── 4. 输出结果 + 记录经验
```

## Phase 5: 慢思考 + 执行 (~2-5s)

### Step 5a: 执行脑执行 WebSearch

```
主脑 → 执行脑:
┌──────────────────────────────────────────────┐
│ Task {                                       │
│   action: "WebSearch",                       │
│   query: "2026年4月中国法定节假日",            │
│   request_id: "req_001"                      │
│ }                                            │
└──────────────────────────────────────────────┘

执行脑处理:
├── 调用 WebSearch 工具
├── 搜索结果:
│   ├── 清明节: 4月4日(周六) - 4月6日(周一), 放假3天
│   ├── 劳动节: 5月1日 (不在4月范围内)
│   └── 其他: 无
└── 返回搜索结果给主脑
```

### Step 5b: 推理脑慢思考 (LLM 调用)

```
推理脑输入:
├── 用户原始问题: "告诉我这个月有没有节假日？"
├── 当前日期: 2026-04-03
├── 记忆脑提供: "2026年清明节是4月4日" (来源: 历史记忆)
├── WebSearch结果: 清明节 4月4-6日放假
└── 任务: 组装自然语言回答

推理脑 LLM 推理:
├── 1. 确认当前月份: 2026年4月
├── 2. 4月法定节假日: 清明节(4月4日-6日, 放假3天)
├── 3. 记忆脑提到清明节, WebSearch也确认, 信息一致
├── 4. 劳动节在5月, 不属于4月
└── 5. 组装回答

推理脑输出:
"2026年4月有一个法定节假日: 清明节，4月4日(周六)至4月6日(周一)放假3天。"
```

### Step 5c: 校验脑双重校验

```
校验脑审查:

① 安全性校验:
├── 有无高危操作？ → 无 (仅 WebSearch 查询)
├── 是否修改文件？ → 否
├── 是否涉及敏感数据？ → 否
└── ✓ 安全通过

② 真实性校验（关键步骤）:

  信息来源追踪:
  ┌─────────────────────────────────────────────────┐
  │ 回答中的每个事实          │ 来源          │ 验证状态 │
  ├──────────────────────────┼──────────────┼─────────┤
  │ "2026年4月有清明节"       │ 记忆脑        │ ✓ 已有   │
  │ "4月4日-6日放假3天"       │ WebSearch    │ ✓ 已验证 │
  │ "4月只有这一个法定节假日"  │ WebSearch    │ ✓ 已验证 │
  └─────────────────────────────────────────────────┘

  来源可信度评分:
  ├── 记忆脑历史记忆: 可信度 0.85 (上次已通过 WebSearch + 用户确认)
  ├── WebSearch 实时查询: 可信度 0.75
  ├── 交叉验证: 记忆 ∩ WebSearch → 一致 ✓
  └── 最终可信度: 0.95 (双重验证通过)

  来源组合: WebSearch + 记忆交叉验证
  → 查表: 可信度 0.95
  → 可信度 > 0.80 → ✓ 可直接输出

③ 输出审核:
  回答: "2026年4月有一个法定节假日: 清明节，4月4日至4月6日放假3天。"
  └── 来源可信度 0.95 → ✓ 直接输出，无需额外警告
```

## 对比场景：系统离线，WebSearch 不可用

假设用户在离线环境问了同样的问题。

### 快思考阶段 (与在线相同)

```
推理脑: 命中经验 → ✓ 相关 (0.88)
记忆脑: 检索到清明节记忆 → ✓ 相关 (0.65)
执行脑: WebSearch 不可用 → 报告工具离线
校验脑: 安全通过
```

### 主脑决策

```
主脑分析:
├── WebSearch 不可用，无法实时验证
├── 只有记忆脑的历史记忆
├── 推理脑仍可做慢思考 (LLM 本地可用)
└── 决策: 推理脑基于记忆组装回答，校验脑标注可信度
```

### 校验脑真实性校验 (关键差异)

```
信息来源追踪:
┌─────────────────────────────────────────────────┐
│ 回答中的每个事实          │ 来源       │ 验证状态  │
├──────────────────────────┼───────────┼──────────┤
│ "2026年4月有清明节"       │ 记忆脑     │ ✗ 未验证  │
│ "4月4日放假"              │ 记忆脑     │ ✗ 未验证  │
└─────────────────────────────────────────────────┘

来源可信度评分:
├── 仅记忆脑历史记忆，无外部验证
├── 记忆创建于 2026-03-15 (19天前)
├── 来源类型: 纯记忆 (无验证)
└── 可信度: 0.50

来源组合: 纯记忆（无验证）
→ 查表: 可信度 0.50
→ 可信度 < 0.60 → 必须标注警告
```

### 用户看到的输出 (离线)

## 对比场景：第二次问同样类型的问题

用户一周后再次输入: "5月有节假日吗？"

### 快思考阶段

```
推理脑:
├── 经验库匹配 → "当月节假日查询" 模式
├── 置信度: 0.92 (上次经验已强化)
├── 直接复用已知路径: [记忆检索 → WebSearch → 交叉验证 → 组装]
└── 跳过慢思考的推理决策环节 → 节省 ~1s

记忆脑:
├── 索引检索 → 搜索 "5月" + "节假日"
├── 结果: 无直接记忆
└── 返回: 无匹配

执行脑:
├── 按推理脑建议路径直接执行 WebSearch
└── 无需主脑二次调度
```

### 总耗时对比

```
首次查询:  ~3-5s (全流程，含慢思考决策)
第二次:    ~1-2s (跳过推理脑慢思考，直接复用路径)
第十次:    ~0.5-1s (路径高度优化，几乎全自动)
```
